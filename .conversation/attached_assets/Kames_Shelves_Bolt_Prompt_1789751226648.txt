Build a complete responsive online bookstore website prototype for a
real Algerian bookstore called:

“Kame’s Shelves”

The website should feel like the online version of an Instagram-based
independent bookstore.

IMPORTANT BRAND DIRECTION

Use the attached visual references of Kame’s Shelves as inspiration.

The brand identity is: - feminine - cozy - youthful - bookish - soft -
playful - warm - Instagram-friendly

Do NOT make it look like a generic Amazon/Shopify bookstore. Do NOT make
it overly corporate or minimalist.

The website should feel like someone took Kame’s Shelves’ Instagram
aesthetic and transformed it into a polished online shopping experience.

COLOR PALETTE

Primary background: Warm cream #FFF9F5

Primary brand color: Baby pink #F7DCE6

Secondary pink: Soft blush #FBECEF

Secondary accent: Dusty lavender #CFC1DD

Dark accent: Deep mauve #80677F

Small secondary accent: Pastel sage/mint #C9DDD6

Text: Soft charcoal #39333A

Use cream as the main page background.

Use baby pink as the strongest visual brand color.

Use lavender and mint only as supporting accents.

Avoid saturated neon colors. Avoid excessive gradients. Avoid making
everything pink.

TYPOGRAPHY

Use an elegant but friendly serif font for: - major headings - featured
book titles - editorial sections

Use a clean rounded sans-serif font for: - navigation - prices -
descriptions - buttons - product information

The typography should feel modern, feminine and editorial.

BRAND NAME

Logo / wordmark:

“Kame’s Shelves”

Include a small book-related symbol or subtle shelf/book icon next to
the logo.

The logo should feel handmade and charming, inspired by the bookstore’s
Instagram profile picture, without directly copying it.

NAVIGATION

Create a clean desktop navigation bar.

Left: Kame’s Shelves logo

Center: - Home - Shop - Categories - New Arrivals - Best Sellers

Right: - Search - Wishlist - Account - Shopping Bag

On mobile, use a hamburger menu and keep Search + Cart visible.

HERO SECTION

Create a large visually attractive hero section.

Main headline:

“Your next favorite book is waiting.”

Supporting text:

“Discover your next read, from romance and mystery to fantasy and
unforgettable stories.”

Buttons:

“Shop Books”

“Explore Categories”

The hero should include a beautiful editorial arrangement of books,
bookmarks, ribbons, flowers or subtle stationery elements.

Use baby pink, cream and lavender around the composition.

Do not create fake generic ecommerce imagery.

The books should look like real physical books.

SHOPPING EXPERIENCE

Create a proper bookstore product catalog.

Include: - Product cards - Realistic book cover images/placeholders -
Book title - Author - Price in DZD - Availability - Rating - Wishlist
heart - Add to Cart button

Example prices should be realistic Algerian bookstore prices such as:
1600 DZD 1800 DZD 2000 DZD 2200 DZD

Use “DZD” consistently.

Show 6–8 book cards.

Add more fictional books to fill the catalog.

Rating - Description - Genre - Format - Add to Cart - Add to Wishlist

“You might also like”

with related books.

DESIGN DETAILS

Use: - soft rounded corners - subtle shadows - thin borders - generous
whitespace - delicate decorative elements - tiny hearts -
stars/sparkles - book icons - bookmarks - subtle floral elements

Keep the decorative elements tasteful.

The design should feel like:

“Pinterest book aesthetic + cozy Instagram bookstore + modern
ecommerce.”

Avoid: - excessive glassmorphism - dark mode - neon colors - huge
gradients - overly technical UI - corporate SaaS aesthetics - excessive
animations - excessive rounded bubble shapes

ANIMATIONS

Add subtle interactions: - book cards slightly lift on hover - wishlist
heart animation - buttons have smooth hover states - category cards have
subtle movement - cart updates smoothly - page transitions are subtle

RESPONSIVENESS

Make the entire website responsive.

Desktop: - spacious editorial layout - 4–5 product cards per row

Tablet: - 3 cards per row

Mobile: - 2 cards per row - sticky mobile navigation - easy-to-use
cart - large touch targets

OVERALL FEEL

The final website should feel like:

Kame’s Shelves’ Instagram account → transformed into a beautiful,
functional online bookstore.

It should preserve the personality of the original bookstore rather than
replacing it with a generic luxury bookstore.

The most important visual identity should be:

BABY PINK + WARM CREAM + LAVENDER

with small touches of MINT.

Make the result polished enough to present as a professional prototype.
